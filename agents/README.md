# Pronghorn Agent Files 🦌

> Copilot coding agent instruction files tailored for Government of Alberta / public sector projects generated by Pronghorn.

## Overview

These agent instruction files provide domain-specific context to GitHub Copilot coding agents working on Pronghorn-generated repositories. They encode Government of Alberta standards, Azure best practices, and public sector compliance requirements so that Copilot agents produce compliant, production-ready code.

## Available Agents

| Agent | File | Purpose |
|-------|------|---------|
| 🏗️ **Terraform** | `pronghorn-terraform.md` | Azure IaC with GoA naming conventions, data residency, tagging standards |
| 🔒 **PIPA Compliance** | `pronghorn-pipa-compliance.md` | PIPA/FOIP privacy compliance, data classification, PIA templates |
| 📊 **SRE** | `pronghorn-sre.md` | Observability, SLOs, alerting, incident response, runbooks |
| 🛡️ **Security** | `pronghorn-security.md` | AppSec reviews, OWASP Top 10, secure coding patterns, CI security |
| ⚙️ **DevOps** | `pronghorn-devops.md` | GitHub Actions CI/CD, Azure deployment, environment promotion, release management |

## Usage in `.github-private` Repository

These agent files are designed to be placed in the organization's **`.github-private`** repository so they apply automatically to all repositories in the Pronghorn sandbox organization:

```
project-pronghorn-sandbox/.github-private/
├── .github/
│   └── copilot-instructions.md    ← Combine relevant agents here
├── agents/
│   ├── pronghorn-terraform.md
│   ├── pronghorn-pipa-compliance.md
│   ├── pronghorn-sre.md
│   ├── pronghorn-security.md
│   └── pronghorn-devops.md
```

### Option 1: Single combined instructions file

Copy the relevant agent content into `.github/copilot-instructions.md` in the `.github-private` repo. This applies to all Copilot interactions across the org.

### Option 2: Per-repo AGENTS.md reference

Reference specific agents in each generated repo's `AGENTS.md`:

```markdown
# Agent Instructions

See the organization's `.github-private` repository for specialized agent instructions:
- Terraform: `agents/pronghorn-terraform.md`
- Compliance: `agents/pronghorn-pipa-compliance.md`
- SRE: `agents/pronghorn-sre.md`
```

## Why `.github-private`?

The `.github-private` repository is a special GitHub repository that provides **organization-wide defaults**:

- Files in `.github/copilot-instructions.md` apply to all Copilot coding agent sessions across the org
- This means every Pronghorn-generated repo automatically inherits GoA compliance, security, and operational standards
- No need to copy agent files into every generated repo — they're inherited
- Centralized updates — change once, apply everywhere
